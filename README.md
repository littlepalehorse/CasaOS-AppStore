# CasaOS-AppStore

**Experimental third-party App Store for [CasaOS](https://github.com/IceWhaleTech/CasaOS).**

An alternative application catalog that extends the default CasaOS app store with additional community-driven and curated applications. This project is **experimental** — features may change, break, or be removed without notice.

## What is this?

CasaOS ships with a built-in app store, but it covers only a fraction of the self-hosted ecosystem. CasaOS-AppStore aims to:

- Provide a **broader selection** of Docker-based applications for your home server
- Offer a **community-curated catalog** with apps not available in the official store
- Serve as a **proof of concept** for extensible app catalogs in the CasaOS ecosystem

## ⚠️ Experimental Status

This is a work in progress. Expect:

- Incomplete features and rough edges
- Potential compatibility issues with newer CasaOS versions
- No formal support or SLA
- Breaking changes at any time

Use at your own risk. Do not run on production systems.
